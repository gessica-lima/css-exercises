 # A common 'modal' style
This one is another very common pattern on the web. The solution to this one is _simple_... but it might not be immediately obvious to you. You'll need to edit the HTML a bit to get everything where it needs to be.

### A hint
Depending on how you approach this one, you might need to revisit the `flex-shrink` property to keep a flex item from getting smashed. In addition, pay attention to the structure of the html, specifically look into adding an additional container surrounding the header, button, main text, cancel, and continue divs; and look into moving the header div to encompass the button as well.

### Self Check

- The blue icon is aligned to the left.
- There is equal space on either side of the icon (the gaps between the icon and the edge of the card, and the icon and the text, are the same).
- There is padding around the edge of the modal.
- The header, text, and buttons are aligned with each other.
- The header is bold and a slightly larger text-size than the text.
- The close button is vertically aligned with the header, and aligned in the top-right of the card.

# Um estilo 'modal' comum
Este é outro padrão muito comum na web. A solução para este é _simples_... mas pode não ser imediatamente óbvia. Você precisará editar um pouco o HTML para que tudo fique no lugar certo.

### Uma dica
Dependendo da sua abordagem, talvez seja necessário revisar a propriedade `flex-shrink` para evitar que um item flexível seja comprimido. Além disso, preste atenção à estrutura do HTML, especificamente considere adicionar um contêiner adicional envolvendo o cabeçalho, o botão, o texto principal, o botão de cancelar e o botão de continuar; e considere mover o div do cabeçalho para que ele também englobe o botão.

## Resultado desejado

![resultado desejado](./resultado-desejado.png)

### Autoverificação

- O ícone azul está alinhado à esquerda.

- Há espaço igual em ambos os lados do ícone (os espaços entre o ícone e a borda do cartão, e entre o ícone e o texto, são iguais).
- Há um espaçamento ao redor da borda do modal.
- O cabeçalho, o texto e os botões estão alinhados entre si.
- O cabeçalho está em negrito e com um tamanho de fonte ligeiramente maior que o do texto.
- O botão de fechar está alinhado verticalmente com o cabeçalho e posicionado no canto superior direito do cartão.
